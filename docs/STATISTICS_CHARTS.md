# Графики страницы «Обзор изменений»

Три графика читают реальный READY-прогон. Новые зависимости не добавлены: React, SVG и CSS. Чеки и сохранённые витрины не изменяются. BEFORE (MASTER) — синий, AFTER (BETA) — зелёный. Переходы со сменой решения отмечены оранжевым.

1. **Матрица итоговых решений.** Строка — BEFORE, столбец — AFTER; число и доля от всех уникальных APP_ID прогона. Итоги по строкам/столбцам дают распределения решений, диагональ — сохранённые решения. Потери — все переходы из APPROVE, приобретения — все переходы в APPROVE; баланс — приобретения минус потери. Знаменатель долей потерь/приобретений и изменения в п.п. — все пары прогона. Одна заявка попадает в одну ячейку.
2. **Сравнение продуктов (компаний).** Два маркера на общей оси 0–100% показывают доли одобрения BEFORE и AFTER. Одна группировка «Продукт (компания)», без переключателя партнёров; таблица ниже и HTML также содержат только продукты. Используется семейство `products` из существующего `/stats`, без объединения или суммирования с партнёрами. Строки отсортированы по убыванию абсолютной разницы; знаменатель — сохранённый paired n группы. Считается одобрение продуктовой попытки на сопоставимых заявках. Группы пересекаются и не складываются. В подсказке — числители/знаменатель, точные доли, изменение и парный CI в п.п. Малые/неинформативные и нулевые группы не скрыты. Справочник названий и статистика используются из существующего `/stats`.
3. **Распределение вероятности одобрения.** По APP_ID сопоставляются одинаковые product_id, названия и типы моделей APPROVAL_PROBABILITY; нужны оба числовых скора. У каждого APP_ID сначала усредняются скоры его сопоставимых продуктов. Затем одна заявка даёт одно наблюдение на каждый срез. Оба распределения используют одну и ту же парную выборку и интервалы [0; 10%), …, [90; 100%]. Вертикальная ось — доля от числа сопоставимых APP_ID, не число продуктовых попыток. Значения за пределами [0; 1] и нечисловые вероятности исключают заявку из распределения; число исключённых и число заявок без сопоставимого скора показаны отдельно. Это вероятность одобрения, не дефолта.

Графики используют абсолютные разницы в п.п., а не относительное изменение; существующие парные CI соответствуют абсолютным разницам. Отдельный график относительного изменения с иным bootstrap не добавлен, чтобы не смешивать единицы и не дублировать сравнение групп. Числа в графиках обычно округлены до одного знака, подсказки — до четырёх. SVG-элементы и ячейки доступны с Tab; подсказки работают при фокусе. Есть загрузка, ошибка с повтором, пустые выборки и мобильная раскладка. На узком экране матрица и гистограмма прокручиваются внутри своей карточки.

API: `GET /api/runs/{id}/stats/charts`, только для владельца READY-прогона. Возвращает `total_apps`, `transitions`, `approvals`, `probability` (n, исключения, средние и 10 интервалов с count/share). Запрос выполняется один раз при открытии графиков/смене прогона и по кнопке повтора; обычное обновление карточек статистики его не повторяет.

Курсор графиков обычный, без знака вопроса. В гистограмме вся область интервала реагирует на наведение, включая нулевые бины: всплывающая подсказка рядом с выбранным бином одновременно показывает доли BEFORE/AFTER, количества заявок и общий знаменатель. Подсказка доступна и с клавиатуры; Escape закрывает её. Общая точная подпись под графиком сохраняется.
